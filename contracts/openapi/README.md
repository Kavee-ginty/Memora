# OpenAPI

`memora-v1.json` is the reviewed OpenAPI 3.1 artifact generated by T05 from the FastAPI application. Do not edit it by hand.

Regenerate it from the repository root:

```powershell
$env:PYTHONPATH = "backend\src"
python -m memora.api.export_openapi --output contracts\openapi\memora-v1.json
```

Check for drift:

```powershell
$env:PYTHONPATH = "backend\src"
python -m memora.api.export_openapi --check --output contracts\openapi\memora-v1.json
```

The artifact must contain only the health paths and shared components. It must not contain `servers` or environment-specific URLs.
